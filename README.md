# Prognósticos Desportivos

App de prognósticos de futebol construída com **Next.js 15**.

- Jogos e estatísticas: **Football-Data.org**
- Logos e imagens: **TheSportsDB**
- Prognósticos: modelo estatístico simples (vantagem de casa + confrontos diretos)

Dados apenas para fins informativos. Jogue com responsabilidade.
